# 绅士漫画独立维护源与登录

核对日期：2026-10-24（香港时间）。当前版本 `wnacg 1.1.0`，来源 `laincat/vensrc`，源码位于 `sources/wnacg.js`。固定漫画 `397513`、关键词“火影”和最低应用版本 `1.0.0` 均保留。

## 登录失败的实际原因

`www.wnacg.com` 与 `www.wnacg.ru` 的公开登录页加载站点自建的 `slider-captcha.js`。脚本注明该流程于 2026-10-23 加入：本人完成滑块后，表单才附带一次性 `slider_pass` 提交。旧源直接提交用户名和密码，没有该流程，因此不能据失败判断密码错误，也不能直接归因为 Cloudflare。

公开登录页及脚本使用不含账号的 GET 请求核对。页面中的 Cloudflare 统计脚本不等于 CF 挑战；以真实挑战响应判断 CF。发布页为 `https://wnacg01.link/`。

## 独立源的处理

- 阅读、分类、章节、缩略图和收藏解析基于官方 1.0.6 保留；账号接口改为 `account.loginWithCookies.validate`，不再提供旧密码直登。
- 访问域名只允许 `www.wnacg.com` 或 `www.wnacg.ru`，默认前者，避免裸域名的 301 跳转及任意域名接收会话。
- 本人在正常浏览器完成站点滑块，再把该域名的 Cookie 填入客户端；源只向相同域名导入会话。
- 验证请求为 `/users-index.html`。HTTP 200 不足以证明登录：必须找到会员页的本站退出登录链接，且没有未登录权限提示。匿名首页、普通登录页、CF 挑战和请求失败均不通过；失败会恢复之前的 Cookie。
- 不保存或输出账号密码，不代解滑块，不生成验证票据。本站密码 Secret 保留在 GitHub 设置中，但工作流已停止注入。

之前 5 个绅士漫画构建已从审阅清单移除：Taototo 私人版、KadishJoey 国内直连版和另一替代版、官方 1.0.6、yelongyue197-svg 1.0.5。发现、清单校验及 Release 校验均只接受本仓库的独立版，其他来源不能重新进入订阅。

## 客户端使用

1. 更新 Vensrc 订阅并安装或替换 `紳士漫畫 1.1.0`。之前安装的不同 key 旧版需要在客户端手动移除，订阅更新不能自动卸载它们。
2. 在源设置中选好域名，然后在本人正常浏览器访问同一域名的 `/users-login.html`，完成登录和滑块。
3. 浏览器打开 `/users-index.html`，确认显示本人会员页面。在开发者工具“网络”中选中该请求，复制请求头的一整行 `Cookie` 值；不要复制响应的 `Set-Cookie`。
4. 在源的 Cookie 登录入口粘贴该行。验证成功才会接受登录；切换域名、会话过期或浏览器网络变化后，应重新导入。

Cookie 等同于登录凭据，只在本人设备和客户端中处理。不要贴到 issue、Actions Secrets、报告或聊天中。已有浏览器完成 CF 验证的会话也可能绑定网络、设备或 User-Agent；导入后仍被要求验证时，源会报错，不能保证 Cookie 可跨环境通用。

## 两个客户端与 CLI 的边界

| 环境 | 接口与结果边界 |
| --- | --- |
| VeneraX 2.3.6 | 支持异步 Cookie 校验；采用会员页实际验证，不使用首页标题作为登录成功依据 |
| Venera-Next 1.18.0 | 同样支持异步 Cookie 校验，使用相同源码和样本独立复测 |
| 最新 venera-patrol-cli | 可调用 Cookie 校验接口；没有本人浏览器会话时，记为 `credentials_missing`／跳过，不能记为登录通过 |
| GitHub Actions | 不接收绅士漫画密码或浏览器 Cookie；两个客户端均测试缺凭据处理，匿名阅读链路另行判断 |

上述客户端版本指 `monitor/clients.json` 中固定、已核验源码哈希的接口版本。VeneraX 的 WebView 成功回调没有等待异步会话校验，Venera-Next 会等待，因此本版采用二者共同支持的 Cookie 校验，不以未经验证的跳转或标题伪造成功。

本地测试只使用明确标记的测试数据验证接口和失败保护。真实账号 Cookie 尚未在本人设备导入验证，不能宣称账号已经登录成功。当次双客户端阅读结果见 [客户端结果](CLIENT_RESULTS.md)，云端登录状态见 [账号结果](ACCOUNT_RESULTS.md)；只有同轮阅读链路满足门槛才进入订阅。
