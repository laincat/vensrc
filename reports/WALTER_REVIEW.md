## 源码分析

- 仓库没有 `index.json`，以 `monitor/upstreams.json` 的 `files` 明确发现 `lizimh.js`；新哈希仅成为待审阅候选。
- 公开首页、搜索、分类和详情使用主备 API，按路径与秒级时间戳计算协议签名，无需个人账号。
- 可选 JWT 用于官方章节 v3 接口；未填写时按图片目录探测章节页数。本轮未提供 JWT，也没有确认账号登录或官方章节顺序。
- 源还提供腾讯／青漫只读评论、图片线路选择和测速。源码未发现动态执行代码、启动子进程或读取本地账号文件。
- 主备元数据 API 使用 HTTP；可选个人 JWT 由用户自行设置，本仓库与匿名巡检不注入该凭据。
